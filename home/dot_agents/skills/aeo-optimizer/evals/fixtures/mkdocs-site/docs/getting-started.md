# Onboarding Overview

Leveraging Ledgerly's best-in-class architecture, stakeholders can operationalize reconciliation workflows at scale. Our solution facilitates seamless alignment between disparate data sources, enabling a single pane of glass for financial truth.

## Prerequisites and Considerations

Prior to commencing the onboarding journey, organizations should ensure appropriate provisioning of credentials in accordance with internal governance policies.

## Procedure

Install the CLI with `pip install ledgerly`, then run `ledgerly init --api-key <key>` to connect your first ledger. Reconciliation runs every 15 minutes by default.
